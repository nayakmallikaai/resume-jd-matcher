## 📝 VIDEO DESCRIPTION

```
Intelligent semantic matching for hiring. Watch how AI analyzes job descriptions and ranks candidates using Claude, vector embeddings, and multi-dimensional analysis—not keyword matching.

## What You'll See
- Two-layer architecture combining vector search (Layer 1) with Claude-powered re-ranking (Layer 2)
- Real demo: Job description → 8 ranked candidates with detailed analysis
- Color-coded strengths (blue) and gaps (pink) for each candidate
- 94% accuracy on ground truth | 98% rejection of adversarial cases
- How it catches what keyword matching misses: domain depth, seniority nuance, stale expertise

## The Problem It Solves
Hiring teams waste hours on resume screening. Keyword matching is brittle. This system understands semantic context—"distributed systems" ≠ "basic backend", "PyTorch fine-tuning" ≠ "OpenAI API consumption".

## Technical Deep Dive
- **Backend**: FastAPI (async)
- **Vector DB**: PostgreSQL + pgvector (IVFFlat indexing)
- **Embeddings**: sentence-transformers (local inference)
- **LLM**: Anthropic Claude Haiku for multi-step reasoning
- **PDF Processing**: pdfplumber for resume extraction
- **Evaluation**: 40+ automated tests, 4 job categories, adversarial candidate testing

## Why Two Layers?
Layer 1 (vector search) gives you speed (~100ms retrieval). Layer 2 (Claude) gives you intelligence—semantic fit assessment, red flag detection, explainable rankings.

## Test Coverage
✓ 94% accuracy on ground truth candidates
✓ 98% rejection of keyword-stuffed candidates
✓ Detects domain mismatches (Python analyst ≠ ML engineer)
✓ Flags stale expertise (Hadoop vs modern Kafka)
✓ Distinguishes API users from model trainers
✓ 40+ automated regression tests
```
